# Дизайн-система: «Soft Stripe»

Собрана из трёх референсов:
1. **Pajama club** — розово-кремовая подписка (полоски, банты, сердечки, серифный заголовок).
2. **Creator portfolio** — кремовый фон, голубые полосы, винно-бордовый акцент, рамки и «папки».
3. **Cupcakes** — мягкие 3D-объекты, круглые подложки, волнистые границы секций, конфетти.

Нравится целиком: стили 1 и 2 (палитра, детали, вставки); из 3 — оформление и подача деталей.

---

## 1. Что общего у референсов

| Аспект | Общее |
|---|---|
| **Настроение** | Нежное, девичье, «уютное», кондитерское. Ощущение подарка и ручной работы. |
| **Фон** | Тёплый кремовый (не чисто белый), крупный воздух вокруг контента. |
| **Палитра** | Пудровый розовый + кремовый + холодный голубой/лавандовый. Один тёмный акцент (бордо/малина) для текста и кнопок. |
| **Типографика** | Контраст: выразительный заголовок (серифный или гротеск с характером) и маленький аккуратный капс/гротеск для подписей. |
| **Паттерн** | Вертикальные полосы как «фирменная» текстура секции (1 и 2). |
| **Детали** | Мелкие декоративные вставки вокруг контента: банты, сердечки, конфетти, точки. Они «рассыпаны», а не выстроены в ряд. |
| **Контент-блоки** | Один центральный «лист» (карточка) поверх узорного фона либо крупный объект на мягкой круглой подложке. |
| **Ритм** | Чередование: спокойная секция с воздухом → насыщенная узорная → спокойная. Каждая секция — одна мысль. |
| **Кнопки** | Малые, плоские или «пилюли», капс, без тяжёлых теней. |
| **Фото/объекты** | Вырезанные предметы без фона, иногда обрезаны краем экрана — создают ощущение глубины и динамики. |

## 2. Палитра

### Основные токены
```css
:root {
  /* Фоны */
  --cream:        #FFF7EE;  /* основной фон страницы */
  --cream-deep:   #FDEBDD;  /* градиент/плашки */
  --white-soft:   #FFFDFB;  /* карточки, «лист» поверх полос */

  /* Розовые */
  --pink-powder:  #FADADD;  /* полосы, подложки, мягкие блоки */
  --pink-soft:    #F6B8C4;  /* кнопки, круги под объекты */
  --pink-main:    #E8708F;  /* заголовки-акцент, сердечки */
  --pink-deep:    #D4547A;  /* hover, активные состояния */

  /* Голубые / лавандовые */
  --blue-powder:  #BBD4F0;  /* полосы (вариант 2), баннеры */
  --blue-lilac:   #E9E9FA;  /* нижняя лента «as seen in», футер-фон */
  --blue-button:  #B8C4EC;  /* вторичные кнопки */

  /* Тёмный акцент */
  --wine:         #6B1B2A;  /* заголовки жирные, плашки, кнопки-«папки» */
  --ink:          #3B2A2E;  /* основной текст (тёплый, не чёрный) */
  --ink-soft:     #7A6468;  /* вторичный текст */

  /* Мелкие акценты */
  --butter:       #F8E3A0;  /* жёлтые банты/конфетти */
  --gold:         #E9C26B;  /* рамки, вензеля */
}
```

### Правила
- **60 / 25 / 10 / 5**: 60% кремовый, 25% розовый (пудра), 10% голубой, 5% акценты (бордо, масло, золото).
- Розовый и голубой — всегда **пастельные**, насыщенность только у `--pink-main` и `--wine`.
- Текст — `--ink` на кремовом; `--wine` для сильных заголовков; `--pink-main` для тонких серифных заголовков-акцентов.
- Контраст текста минимум 4.5:1. Розовый `--pink-main` на кремовом использовать только для крупных заголовков (≥ 32px).
- Один экран — максимум **две** «основные» пастели + кремовый.

## 3. Типографика

### Пары шрифтов
| Роль | Вариант A (как референс 1) | Вариант B (как референс 2) |
|---|---|---|
| **Display** | *Cormorant Garamond* / *Playfair Display* Light-Regular — тонкий высококонтрастный сериф, розовый цвет | *Lora* / *DM Serif Display* Bold — плотный сериф, бордовый цвет |
| **Body** | *Jost* / *Montserrat* 400 — геометрический гротеск | *Poppins* / *Jost* 400 |
| **Label / Eyebrow** | тот же гротеск, 500, капс, трекинг +0.12em | то же |
| **Декор (редко)** | рукописный (*Caveat*, *Pacifico*) — только для 1–2 слов-акцентов в духе референса 3 | |

**Рекомендация:** Display — *Cormorant Garamond* (тонкий, розовый) для лёгких секций и *Lora Bold* (бордовый) для плотных/«сильных» блоков. Body — *Jost*.

### Шкала (desktop / mobile)
| Токен | Размер | Межстрочный | Применение |
|---|---|---|---|
| `display-xl` | 72 / 44 px | 1.0 | Hero-заголовок |
| `display-l`  | 48 / 34 px | 1.05 | Заголовки секций («Build your box») |
| `display-m`  | 32 / 26 px | 1.15 | Подзаголовки, имена карточек |
| `body-l`     | 18 / 16 px | 1.6 | Лид-абзац |
| `body`       | 15 / 15 px | 1.6 | Основной текст |
| `label`      | 11–12 px | 1.4 | Капс-подписи, кнопки, «STEP ONE», «MADE TO UNWIND» |

### Правила
- Заголовок **центрируется** в лёгких секциях и **выравнивается по левому краю** в плотных/портфолио-секциях.
- Каждая секция начинается с **eyebrow** (маленький капс сверху) → заголовок → короткий абзац (≤ 3 строк, ширина ≤ 38ch) → CTA.
- Допустим смысловой акцент в заголовке: одно слово курсивом или в кавычках «me-time».
- Ширина абзацев ограничена (`max-width: 38–55ch`), в центрированных блоках — узкая колонка.
- Нижний регистр + капс разделены по ролям: капс — только label.

## 4. Сетка и раскладка

- **Контейнер:** 12 колонок, `max-width: 1200px`, gutter 24px, боковые поля 16px (mobile) / 48px (desktop).
- **Основной приём — симметричная центральная колонка** (hero-текст, «steps») + **асимметричные «выступы» по краям** (объект справа, рука со стаканом слева, обрезанные краем экрана).
- **Три равные колонки** для шагов/преимуществ с тонкими вертикальными разделителями (1px `--pink-powder`).
- **Шахматка «объект ⟷ текст»** (референс 3): круглая подложка с предметом слева, текст справа; следующий блок — зеркально. Блоки слегка смещены по вертикали, не по жёсткой линии.
- **Портфолио-коллаж** (референс 2): карточки разных размеров на полосатом фоне, перекрывают друг друга и частично выходят за край.
- Мобильная версия: всё в одну колонку, декор уменьшается на 60% и остаётся только по краям.

---

## 5. Пространство и ритм блоков

**Шкала отступов (8px-база):** 4 · 8 · 16 · 24 · 32 · 48 · 64 · 96 · 128

| Место | Значение |
|---|---|
| Вертикальный padding секции | 96–128 px (desktop), 64 px (mobile) |
| Между eyebrow → заголовок → текст → кнопка | 16 · 24 · 32 |
| Внутренний padding карточки-«листа» | 48–64 px |
| Gap в сетке шагов | 48 px |

**Паттерн чередования секций (сверху вниз):**
1. **Hero** — кремовый, воздух, центральная колонка + 2 объекта по краям, 4–6 мелких декоров.
2. **Полосатая секция** — фон-полоски (`--pink-powder` / `--cream`), по центру белая карточка «лист» с контентом.
3. **Объект-на-подложке** — кремовый, круглые пастельные подложки, шахматка.
4. **Социальное доказательство** — лента `--blue-lilac` с логотипами, центрированный eyebrow «AS SEEN IN ♥».
5. **Плотная секция** — бордовые плашки/«папки» на голубых полосах (портфолио, кейсы, тарифы).
6. **Футер** — волнистая розовая граница (как в референсе 3), мелкий капс.

Правила ритма:
- Нельзя подряд две «плотные» секции; между ними — воздух.
- Каждая секция заканчивается **одним** CTA.
- Смена фона между секциями — либо **волна**, либо **полоса**, либо резкая линия лилового (не мягкий градиент).

## 6. Паттерны и разделители

### Полосы (signature)
```css
.stripes-pink {
  background: repeating-linear-gradient(90deg,
    var(--cream) 0 28px, var(--pink-powder) 28px 56px);
}
.stripes-blue {
  background: repeating-linear-gradient(90deg,
    var(--cream) 0 40px, var(--blue-powder) 40px 80px);
}
```
- Широкие полосы (28–40px) для декоративных секций; тонкие (2–4px) — для ткани/пижамных вставок на карточках товара.
- Полосы всегда **вертикальные**. Поверх — «лист» `--white-soft` без тени или с очень мягкой.

### Волнистая граница (из референса 3)
- Облачный/«кремовый» край: SVG-волна `--pink-soft` / `--pink-powder` шириной 100%, высота 60–120 px.
- Использовать на стыке hero → следующая секция и перед футером.

### Тонкий разделитель
- `1px solid var(--pink-powder)`, либо ряд из «⋯ ♥ ⋯».

## 7. Декоративные вставки и детали

Ключевая часть стиля. Все — **рисованные/акварельные, с тонкой обводкой**, лёгкая неровность линии.

| Элемент | Где | Цвет |
|---|---|---|
| **Банты** (outline или заливка) | над иконками шагов, на углах карточек и «папок», на хвостиках заголовков | розовый, голубой, масляный |
| **Сердечки** (контурные, 3 размера) | вокруг hero, рядом с заголовками, в eyebrow («AS SEEN IN ♥») | розовый, голубой, масло |
| **Конфетти / точки** | вокруг объектов (референс 3) | розовый, масло, терракот |
| **Золотая рамка-вензель** | вокруг портретов/главного фото (референс 2) | `--gold` на розовом |
| **«Папки»-табы** | категории/услуги, бордовые, с бантиком в углу | `--wine` + кремовый текст |
| **Круглые подложки** | под предметом, 240–360px, мягкий градиент пастели | `--pink-powder`, `--butter`, `--cream-deep` |
| **Мини-иконки** | в карточках-описаниях, контурные, круглая плашка | `--pink-main` |

Правила расстановки:
- 4–8 декоров на hero, 2–4 на остальных секциях.
- Размеры **неравные** (16 / 24 / 40 px), небольшие повороты ±12°.
- Никогда не пересекают текст; держатся в «орбите» объекта или заголовка.
- Один декор-**герой** в секции (крупный бант или объект), остальные — мелкая россыпь.

## 8. Работа с объектами и фото (идея референса 3)

- Предметы **вырезаны** (без фона), с мягкой тенью `0 24px 40px -16px rgba(212,84,122,.25)`.
- Крупные, «вкусные»: объект занимает 40–55% ширины блока.
- Под объектом — **круглая подложка** или тарелка-плашка цвета пастели; объект слегка выходит за её границу.
- Допустимо обрезать объект краем экрана (как рука со стаканом, пижама справа).
- Портреты: в рамке (золото/розовый) с лёгким поворотом или в «стикере» с белой обводкой и тенью.
- Цветовая коррекция: тёплая, слегка приглушённая, без глубоких чёрных.

## 9. Компоненты

### Кнопки
| Тип | Стиль |
|---|---|
| **Primary** | фон `--blue-button` или `--pink-soft`, текст `--ink`, капс 11–12px, трекинг .14em, padding 16×32, радиус 2px (референс 1) |
| **Pill CTA** | фон `--pink-soft`, радиус 999px, лёгкая тень (референс 3, 2) |
| **Wine** | фон `--wine`, текст `--cream`, радиус 999px, с мини-курсором/стрелкой (референс 2) |
| **Hover** | сдвиг вверх 2px, фон на тон глубже; без резких анимаций |

### Карточки
- «Лист»: `--white-soft`, без обводки или `1px --pink-powder`, радиус 0–4px (редакционный) либо 24–32px (кондитерский).
- Карточка-инфо (референс 2): светло-голубая, обводка 1px `--blue-powder`, радиус 12px, иконка слева сверху, заголовок 600, текст 13px.
- Плашка-метка («PACKAGE 03», «STARTING AT $550»): бордовая, капс, радиус 2px.

### Шаги (Step 1–3)
- Иконка-бант (разный цвет на каждом шаге: масло → розовый → голубой) → «STEP ONE» капсом → 2 строки текста по центру; вертикальные тонкие разделители.

### Навигация
- Лёгкая, в одну строку, 13–14px, `--ink`; логотип в круге пастельного цвета (референс 2) или рукописный.
- CTA-пилюля справа.

### Лента логотипов
- Фон `--blue-lilac`, логотипы монохромно-розовые/ink, равномерно по ширине, eyebrow сверху.

### Формы
- Поля с нижней линией или мягким прямоугольником `--white-soft`, фокус — обводка `--pink-main`.

## 10. Движение (минимум)

- Мягкое появление при скролле (fade + 12px вверх, 500–700ms, ease-out).
- Декор: лёгкий «float» ±6px, 4–6s, для 2–3 крупных элементов; уважать `prefers-reduced-motion`.
- Hover по карточкам: подъём 4px + тень, по бантам: поворот 6°.

---

## 11. Тон и контент

- Голос: тёплый, ласковый, лёгкий («me-time», «cozy», «unwind»).
- Короткие фразы, глаголы в 2-м лице, без жаргона и канцелярита.
- Заголовок — образ или выгода; подзаголовок — конкретика в 1–2 строки.
- Допустимы смайлы-сердечки ♥ как разделители, но не в тексте абзацев.

---

## 12. Чек-лист «в духе системы»

- [ ] Фон кремовый, не белый.
- [ ] Есть полосатая секция и/или волнистая граница.
- [ ] Не более 2 пастелей + бордовый акцент на экране.
- [ ] Заголовок серифный, eyebrow капсом.
- [ ] Декор: банты/сердечки/конфетти разных размеров, не пересекают текст.
- [ ] Объекты вырезаны, на круглой подложке, с мягкой тенью.
- [ ] Один CTA на секцию, маленький, капсом.
- [ ] Воздух: padding секций ≥ 96px desktop.
- [ ] Контраст текста ≥ 4.5:1.

---

## 13. Чего избегать

- Холодный белый фон, чёрный текст `#000`.
- Насыщенные неоновые розовые, жёсткие тени.
- Горизонтальные полосы (ломают фирменный вертикальный ритм).
- Более 3 шрифтов; рукописный шрифт для абзацев.
- Равномерно расставленные декоры «по сетке» — они должны выглядеть рассыпанными вручную.
- Плотные тёмные секции подряд.
