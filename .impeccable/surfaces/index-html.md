# Surface: лендинг мастера по наращиванию ресниц (index.html)

Mode: Persuade. Аудитория: девушки, которые не хотят каждое утро красить ресницы и хотят просто прийти к мастеру. Действие: записаться (форма на странице, Telegram, телефон). Доказательства: реальных фото, отзывов, цен нет — только заглушки `[...]`, иллюстрации помечены как иллюстрации. Структура экранов подтверждена пользователем: hero со скролл-сборкой ресниц → «без туши» → эффекты → как проходит → мастер → прайс → до/после → запись → футер. Видео/кадры hero пользователь сгенерирует позже; сейчас сцена рисуется кодом и заменяема.

## Direction contract

THESIS: Страница сама «наращивает» ресницы: первый экран — закрытый глаз, на котором по скроллу ресницы изолируются, удлиняются, собираются в пучки и темнеют до глубокого чёрного. Отказ от шаблона «фото девушки + заголовок + кнопка + три карточки услуг».

OWN-WORLD: Кремовые листы на голубых вертикальных полосах (по второму референсу пользователя): кремовая основа, голубые полосы по краям и в разделах, бордовые плотные заголовки Lora Bold, текст Montserrat, бордовые пилюли-кнопки и бордовые папки с розовыми бантами, розово-золотая рамка портрета, голубые карточки с тонкой обводкой; рукописного шрифта нет, курсив Lora для пометок.

STORY: За первый скролл посетительница видит результат без туши, понимает, какие бывают эффекты и как проходит процедура, знакомится с мастером, видит цены и записывается.

FIRST VIEWPORT: По центру крупный иллюстрированный закрытый глаз (~70% ширины на десктопе, ~95% на мобильном) на розово-голубом поле, над ним заголовок «Красивые ресницы каждое утро. Без туши.», под ним кнопка «Записаться» и ссылка Telegram; слева шкала этапов сборки; вокруг плавают банты и сердечки; навигация с пилюлей «Записаться» всегда видна.

FORM: Закреплённая сцена со scrub-анимацией + чередование полос/полей/листов. Направление закреплено брифом пользователя (reference/design-system.md и утверждённая структура экранов); ролл прошёл без челленджеров (degraded) и закреплённое решение пользователя важнее ролла. seed:2688ac7f9f7d5aa7
