# Сайт мастера по наращиванию ресниц

Одностраничный статичный лендинг: HTML, CSS и JS без сборки.

## Запуск

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080/. Через `file://` модули JS не загрузятся.

## Где что

- `index.html` — вся страница: hero, «без туши», эффекты, как проходит, мастер, цены, до/после, запись, футер.
- `css/tokens.css` — цвета, шрифты, отступы. Цвета берутся только отсюда.
- `css/site.css` — стили секций и анимаций появления.
- `js/lashes.js` — рисованный глаз и сборка ресниц, схемы эффектов.
- `js/main.js` — прокрутка, подсказки hero, появления, слайдер «до/после», форма.
- `assets/fonts/` — Oranienbaum, Jost, Caveat (с кириллицей), подключены локально.
- `reference/design-system.md` — дизайн-система.

## Что заменить на реальное

Всё в квадратных скобках — заглушки (класс `.stub`): название, имя мастера, фото, рассказ о себе, цены, Telegram, телефон, адрес, ссылка на политику.

- Telegram: `href="https://t.me/"` у ссылок с `data-stub="telegram"` → `https://t.me/<ник>`.
- Телефон: `href="tel:+70000000000"` → реальный номер.
- Фото мастера: заменить содержимое `.frame__photo` на `<img src="..." alt="...">`.
- До/после: сейчас там рисунок; для фото замените два `<canvas>` в `.compare` на `<img>` с теми же классами.

## Отправка заявок

Форма валидирует имя и телефон. Если у `<form data-endpoint="">` пустой адрес, заявка никуда не уходит: показывается «Заявка у меня!», данные пишутся в консоль. Чтобы заявки приходили, впишите адрес обработчика (например, Formspree или свой бот) в `data-endpoint` — форма отправит JSON POST-запросом.

## Своё видео в hero

Сейчас сборка ресниц рисуется кодом. Чтобы поставить сгенерированный ролик:

1. Положите файл в `assets/video/hero.mp4`.
2. В `index.html` раскомментируйте `<video class="hero__video" data-scrub ...>` внутри `.hero__scene`.
3. Удалите `<canvas data-eye>` или оставьте: при наличии видео холст рисует только линии к подсказкам.

Видео перематывается прокруткой, поэтому кодируйте его с ключевым кадром на каждом кадре, иначе перемотка дёргается:

```bash
ffmpeg -i source.mp4 -an -c:v libx264 -g 1 -crf 22 -pix_fmt yuv420p -movflags +faststart assets/video/hero.mp4
```

Тайминг этапов (доля прокрутки hero): свои ресницы 0–10 %, изоляция 10–42 %, длина 42–62 %, объём 62–78 %, цвет 78–100 %. Подсказки и шкала этапов привязаны к этим долям (`WINDOWS` в `js/main.js`, `STAGES` в `js/lashes.js`); под новый ролик поправьте их и координаты `PLACE`.
